# Shared interfaces

All URLs below are relative to the API root. Responses are JSON unless noted. Write/inference requests require `Authorization: Bearer <key>`; local default key is `local-development-only`. Read-only metadata/metrics routes have no private data. UI live API defaults to Vite proxy `/`; public Pages build sets `VITE_DEMO_MODE=1` and reads `demo.json` using `import.meta.env.BASE_URL`.

## Runtime Python interfaces

`switchyard.models.bootstrap(root: Path, seed=42) -> dict` creates two ONNX models and `registry.json` plus `samples.json`. Model version IDs: `digits-logreg-v1`, `digits-rf-v2`. Use sklearn's bundled digits dataset; deterministic stratified holdout. No remote downloads.

`ModelRegistry(root: Path)` validates checksum/model metadata, creates CPU ONNX sessions and warms them. Methods `list_models() -> list[dict]`, `sample_data() -> list[dict]`, `predict(version: str, rows: np.ndarray) -> np.ndarray` (n×10 probabilities); property `versions -> list[str]`. Unknown versions raise KeyError.

Each model metadata dict: `version,title,framework,accuracy,test_samples,train_samples,sha256,artifact_bytes,created_at,description`. `framework='onnxruntime'`; accuracy fraction. Sample dict: `id,label,pixels` (64 values).

`switchyard.batching.DynamicBatcher(registry,max_batch_size=16,max_wait_ms=8,queue_capacity=128)` exposes `async start()`, `async close()`, `async predict(version,features,timeout_ms=2000) -> BatchResult`, and `stats() -> dict`. `BatchResult` dataclass: `probabilities` list[float] length10, `queue_ms`, `inference_ms`, `batch_size`. Each queue is per-version and bounded at queue_capacity. `stats` includes `queue_depth,inflight,batches,max_batch_size,queue_capacity_per_version`. Exceptions: `QueueFullError`, `DeadlineExceededError`, `UnavailableError`. No backend imports needed in these modules.

## REST shapes

- `GET /health` -> `{status:'ok',ready:true,demo_mode:bool}`. `GET /ready` ->200 when warmed, otherwise503.
- `GET /v1/models` -> `{models:Model[]}`.
- `GET /v1/samples` -> `{samples:Sample[]}`.
- `GET /v1/policy` -> Policy below.
- `GET /v1/events` -> `{events:Event[]}` newest first, maximum100.
- `GET /v1/metrics` -> Metrics below.
- `GET /metrics` -> Prometheus text exposition.
- `POST /v1/predict` body `{pixels:number[64],routing_key?:string,timeout_ms?:number}` -> `{request_id,version,prediction:int,probabilities:number[10],latency_ms,queue_ms,inference_ms,batch_size,policy_revision}`. On overload429; deadline504; candidate fault503. Errors use `{detail:string}`; malformed requests422.
- `POST /v1/rollouts` body `{candidate:string,weight:number,expected_revision:int,guardrails?:{max_error_rate:number,max_p95_ms:number,min_samples:int,window_size:int}}` -> Policy. Weight range0.05–0.5. A candidate's quality must be at least champion accuracy−0.03. Active rollout cannot be replaced without first rollback/promote.
- `POST /v1/rollouts/promote` body `{expected_revision:int}` -> Policy, requires current canary observations satisfy guardrails and minimum sample count.
- `POST /v1/rollouts/rollback` body `{expected_revision:int,reason?:string}` -> Policy.
- `POST /v1/chaos` body `{enabled:bool,error_rate:number,latency_ms:number}` -> `{enabled,error_rate,latency_ms}`. Demo-only; active canary required when enabling. Root provides independent `GET /v1/chaos` same shape.

Policy: `{revision:int,champion:string,canary:string|null,weight:number,status:'inactive'|'running'|'rolled_back'|'promoted',rollout_id:string|null,guardrails:{max_error_rate,max_p95_ms,min_samples,window_size},updated_at:ISO,reason:string|null}`.

Event: `{id:int,at:ISO,type:string,message:string,revision:int,details:object}`. Types `rollout_started,promoted,manual_rollback,automatic_rollback,restart_rollback,chaos_changed`.

Metrics: `{window_seconds:60,totals:{requests,errors,rejections},aggregate:{p50_ms,p95_ms,p99_ms,throughput_rps,error_rate},by_version:[{version,requests,errors,error_rate,p50_ms,p95_ms,queue_ms,inference_ms}],timeseries:[{at:ISO,requests,errors,p95_ms}],queue:{queue_depth,inflight,batches,max_batch_size,queue_capacity_per_version}}`.

## Static recorded demo

`frontend/public/demo.json`: `{captured_at:ISO,source:string,models:Model[],samples:Sample[],frames:[{label:string,policy:Policy,metrics:Metrics,events:Event[]}],benchmarks?:object}`. Three minimum frames: Baseline, Canary fault, Recovered. This will be generated by a real integration scenario after backend completion. Frontend may initially provide an empty loading state; do not invent measured numbers. Recording frame selection must be clearly described as replay/inspection, with live mutating controls disabled in static mode.

## App invocation

`uvicorn switchyard.api:app --host 127.0.0.1 --port 8090` (one worker). Environment `SWITCHYARD_DATA_DIR` default `var`, `SWITCHYARD_MODEL_DIR` default `models`, `SWITCHYARD_API_KEY` local default above, `SWITCHYARD_ENV` default `demo` or `production`, `SWITCHYARD_MAX_BATCH_SIZE` default16, `SWITCHYARD_MAX_WAIT_MS` default8, `SWITCHYARD_QUEUE_CAPACITY` default128. Lifespan bootstraps missing local models then loads/warms. Root `create_app` may take injected registry/batcher for tests.
