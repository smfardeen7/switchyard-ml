# Switchyard console

React + TypeScript + Vite frontend. It consumes the API shapes in `../docs/CONTRACT.md`.

```sh
npm ci
npm run dev
```

Live mode opens on port **5180** and proxies `/v1`, `/health`, `/ready`, `/metrics` and API docs to `http://127.0.0.1:8090`. `VITE_API_PROXY` changes the development proxy destination. `VITE_API_ROOT` can point to another API root if that server permits the browser origin. The bearer token is held only in React state; the local demo default is `local-development-only`. Nothing is written to browser storage.

```sh
npm run build
VITE_DEMO_MODE=1 VITE_BASE_PATH=/switchyard-ml/ npm run build
VITE_BASE_PATH=/switchyard-ml/ npm run preview
```

`VITE_DEMO_MODE=1` builds an explicitly read-only recorded console. It loads `import.meta.env.BASE_URL + 'demo.json'`; `public/demo.json` must be generated by the real integration recording script. Missing or malformed recordings display an error, never substitute invented measurements. The recording is immutable during a page session; frame selection inspects snapshots and does not perform live actions. API writes are blocked both at the UI and API-client boundary.

Live mode polls read endpoints every two seconds. Controls send actual inference and release requests, including `expected_revision` for rollout changes. Server-side quality and observation guardrails remain authoritative. A 120-request exercise uses 12 asynchronous workers, shows successes/failures, and sends a distinct routing key per request. Fault injection is available only when the API reports demo mode and an active canary exists. The frontend does not upload or execute model artifacts.

Docker uses nginx to serve the production bundle and proxy the API at `api:8090`. The container build is live mode by default. Every numeric metric shown is returned by the API or the generated recording; slider values are configuration proposals, not observed measurements.

## Local verification

TypeScript checking and both live/recorded production builds passed. Browser verification against the real API confirmed model metadata and expandable automatic-rollback evidence; the parent integration run checks live inference and release actions. The generated recording loaded successfully under `/switchyard-ml/`, showed the capture timestamp, changed between real frames, and disabled inference, rollout, burst and chaos writes. At a 390px mobile viewport the document width was also 390px. No browser warning/error entries were present during the normal-render checks.
